Prompt Library / Copy, adapt, verify

A better first draft starts with a better ask.

Use these prompts as starting points. Add context you are allowed to share, explain what a good result looks like, and check the output before using it.

Ready-to-use prompts

Start with a useful first pass

Draft a clear message

For a routine message using non-sensitive context.

Draft a [type of message] for [audience]. The goal is [goal]. Use a [tone] tone and keep it under [length]. Include [key points]. If anything important is missing, ask me before drafting.

Explore a topic

Use this to plan research, then verify claims with reliable sources.

I am learning about [topic] for [purpose]. Suggest the key questions I should investigate, define unfamiliar terms, and list what evidence would help answer each question. Separate established facts from open questions. Do not invent citations.

Summarize supplied material

Only include material you are permitted to share with the tool.

Summarize the material below for [audience]. Return: 1) the main point, 2) up to five supporting details, and 3) unresolved questions. Preserve caveats and distinguish what the source says from your interpretation. Material: [paste approved text]

Prompt templates

Fill in the blanks

A reusable prompt can include a role, a task, the context, constraints, and the shape of the answer. Replace bracketed text with safe, relevant details.

You are helping me with [task].
Context: [relevant, approved information]
Audience: [who will use the result]
Requirements: [constraints, tone, length, format]
Before you answer: ask up to [number] questions if essential information is missing.
Return: [desired output structure]

Prompt techniques

Help the tool help you

Give context

Describe the goal, audience, and relevant constraints. Leave out information you should not share.

Specify the output

Ask for a format, level of detail, length, or tone that will make the answer easier to review.

Work in steps

Ask for an outline or questions first, then refine one section at a time.

Check the result

Request assumptions and uncertainties, then verify important claims independently.
